Aiyiyi 算法题目集 — 题解

题解作者：Claude Opus 4.8（1M context）。 配套题面见 set1_CN.md。仅作算法分析，不附参考代码。

题目一：区间内线段计数 — CDQ 分治

转化

把每条线段 \((L', R')\) 看成平面上的一个点 \((L', R')\)。查询 \((L, R)\) 要数的是满足

\[ L \le L' \quad\text{且}\quad R' \le R \]

的点数，也就是一个二维偏序（dominance）计数。此外，一次查询只能统计在它之前加入的线段；初始的 \(k\) 条线段视为发生在时刻 \(0\) 的 add 操作。

于是每个事件带三个坐标，整道题是一个 三维偏序计数：

维度 「查询计入该 add」的条件
时间 \(t\) \(t_{\text{add}} < t_{\text{query}}\)
左端 \(L\) \(L_{\text{add}} \ge L_{\text{query}}\)
右端 \(R\) \(R_{\text{add}} \le R_{\text{query}}\)

这正是 CDQ 分治 的标准场景。

算法

CDQ 每一层消掉一维：

  1. 时间维 —— 事件本身按时间有序。把事件序列对半分，递归处理左右两半，再让 左半 的 add 贡献给 右半 的 query。这样时间限制就被分治结构天然消掉。
  2. 左端 \(L\) —— 归并时把两半事件按 \(L\) 降序扫描。相等时让 add 排在 query 前面（因为 \(L_{\text{add}} = L_{\text{query}}\) 仍满足 \(L_{\text{add}} \ge L_{\text{query}}\)）。扫到某个 query 时，前面已处理的所有 add 都满足 \(L_{\text{add}} \ge L_{\text{query}}\)。
  3. 右端 \(R\) —— 用一棵以离散化后的 \(R\) 值为下标的树状数组：扫到 add 就在位置 \(R'\) 处 \(+1\)；扫到 query 就查询下标 \(\le R\) 的前缀和。

把一个按 \(L\) 预排序的全局数组沿递归归并下去（和归并排序一样），就能避免每层重新排序。

复杂度

时间 \(O(N \log^2 N)\)，空间 \(O(N)\)，其中 \(N = k + m \le 2\times10^6\) —— 一个 \(\log\) 来自分治深度，一个来自树状数组。

备选解： 按时间顺序在线处理，配合二维树状数组（树状数组套树状数组）或归并树，同为 \(O(N \log^2 N)\)。CDQ 在常数和内存上更优，是本题的标准解。

题目二：欧拉函数 LCM 求和 — 莫比乌斯反演

降维到「按值统计」

令

\[ a_v = \#\{\, i \le n : \varphi(i) = v \,\}. \]

由于 \(\varphi(i) \le i \le n\)，所有欧拉函数值都落在 \([1, n]\)，故取值域 \(M = n\)。目标和从「对下标的二重循环」化为「对取值的二重循环」：

\[ S = \sum_{i,j} \operatorname{lcm}(\varphi(i),\varphi(j)) = \sum_{u,v} a_u a_v \operatorname{lcm}(u, v) = \sum_{u,v} a_u a_v \frac{uv}{\gcd(u,v)}. \]

莫比乌斯反演

设 \(g = \gcd(u, v)\)，\(u = gx,\ v = gy,\ \gcd(x, y) = 1\)，则 \(\dfrac{uv}{g} = gxy\)：

\[ S = \sum_{g} g \sum_{\gcd(x,y) = 1} (a_{gx}\,x)(a_{gy}\,y). \]

用 \([\gcd(x,y) = 1] = \sum_{d \mid \gcd(x,y)} \mu(d)\) 展开互质条件，再令 \(x = dx',\ y = dy'\)，按 \(T = gd\) 重新编号。内层的除数和可化简为

\[ \sum_{d \mid T} \mu(d)\, d = \prod_{p \mid T}(1 - p) \]

（两边都是积性函数，且在素数幂 \(p^k\) 处都等于 \(1 - p\)）。于是整体收成一个单层求和：

\[ \boxed{\,S = \sum_{T=1}^{M} h(T)\, P(T)^2\,}, \qquad h(T) = T \prod_{p \mid T}(1 - p), \qquad P(T) = \sum_{k \ge 1} a_{kT}\cdot k. \]

两个量的求法

  • \(h(T)\) 是积性函数，\(h(p^k) = p^k (1 - p)\)，一遍线性筛即可求全部 \(T\)。（维护 \(r(T) = \prod_{p\mid T}(1-p)\)：扩展 \(i \to ip\) 时，若 \(p \mid i\) 则 \(r(ip) = r(i)\)，否则 \(r(ip) = r(i)(1-p)\)；最后 \(h(T) = T \cdot r(T)\)。）
  • \(P(T) = \sum_{k} a_{kT}\, k\) 通过对每个 \(T\) 枚举倍数得到（调和级数循环），复杂度 \(O(M \log M)\)。注意 \(P\) 是货真价实的整数求和，全程不需要求逆元。

正确性验证

小多重集即可验证公式： - \(\{1, 2\}\)：直接求和 \(= 7\)；公式 \(h(1)P(1)^2 + h(2)P(2)^2 = 1\cdot 3^2 + (-2)\cdot 1^2 = 7\)。✓ - \(\{2, 3\}\)：直接求和 \(= 17\)；公式 \(1\cdot 5^2 + (-2)\cdot 1^2 + (-6)\cdot 1^2 = 17\)。✓

复杂度

线性筛求 \(\varphi\) 与 \(h\) 为 \(O(n)\)，调和循环求全部 \(P(T)\) 为 \(O(n \log n)\)，末尾求和 \(O(n)\)。整体 \(O(n \log n)\)，在 \(n \le 10^6\) 下绰绰有余。所有运算对 \(998244353\) 取模。

题目三：共链点集计数 — 点分治 + NTT

按端点计数

一个点集落在同一条简单路径上，当且仅当它的 Steiner 树（连接它的最小子树）本身就是一条链。对任意 \(|S| \ge 2\) 且构成链的集合，链的两个端点 \(\{a, b\}\) 唯一确定且都属于 \(S\)（Steiner 树的叶子必是终端点），其余被选点都严格落在 \(a, b\) 之间。

这给出一个无重复、无遗漏的计数方式。\(a\to b\) 路径上有 \(d(a,b) - 1\) 个内部点，一个以 \(\{a,b\}\) 为端点的 \(K\) 元集合从中选 \(K - 2\) 个。每个合法集合在它唯一的端点对下恰好被数一次，故对 \(K \ge 2\)：

\[ \mathrm{Ans}(K) = \sum_{\{a,b\}} \binom{d(a,b) - 1}{K - 2}, \qquad \mathrm{Ans}(1) = n. \]

令 \(c_d = \#\{\{a,b\} : d(a,b) = d\}\) 为树上距离分布，则

\[ \mathrm{Ans}(K) = \sum_{d \ge 1} c_d \binom{d - 1}{K - 2}, \qquad K \ge 2. \]

验算： \(K = 2\) 时 \(\sum_d c_d = \binom{n}{2}\)（任意点对都合法）。链 \(1\text{-}2\text{-}3\) 得 \(\mathrm{Ans} = (3, 3, 1)\)；\(4\) 点星图得 \((4, 6, 3, 0)\) —— 都与暴力枚举一致。

第一步 —— 点分治 + NTT 求距离分布

求 \(c_d\) 正是 Frequency Table of Tree Distance。用点分治：对每个重心，在其连通块内构造深度生成多项式 \(F(x) = \sum_v x^{\operatorname{dist}(\text{重心}, v)}\)。则 \(F(x)^2\) 按总深度统计有序点对，但会多算落在同一子树内的对（它们真实的路径并不经过重心）。对每个儿子子树 \(i\) 减去 \(F_i(x)^2\) 即可：减法会让对角线 \((u,u)\) 项相消，重心自身的贡献保留，最后除以 \(2\) 把有序对转成无序对。每次多项式乘法用 NTT 完成。

点分治同一层上各重心的子树大小之和为 \(n\)，共 \(O(\log n)\) 层，故总代价 \(O(n \log^2 n)\)。

第二步 —— 一次 NTT 完成二项式变换

把 \(c_d\) 转成答案是一个二项式变换。记 \(j = K - 2\)、\(i = d - 1\)：

\[ \mathrm{Ans}(j + 2) = \sum_{i \ge 0} c_{i+1}\binom{i}{j} = \frac{1}{j!}\sum_{i \ge j} \bigl(c_{i+1}\, i!\bigr)\frac{1}{(i - j)!}. \]

令 \(e_i = c_{i+1}\, i!\)。求和 \(\sum_i e_i\,\tfrac{1}{(i-j)!}\) 是序列 \((e_i)\) 与序列 \(\bigl(\tfrac{1}{t!}\bigr)\) 的一个相关（correlation）；把 \((e_i)\) 翻转后即化为普通卷积，用一次 NTT 算出，再把位置 \(j\) 处的结果乘上 \(\tfrac{1}{j!}\) 即可。

复杂度

整体 \(O(n \log^2 n)\)，瓶颈在点分治；二项式变换只额外贡献 \(O(n \log n)\)。在 \(n \le 10^5\) 下从容通过。所有运算对 \(998244353\) 取模。
